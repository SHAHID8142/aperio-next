Derive a sitemap from the reviewed requirements before designing any page. State each page's single intent and its primary action. Define navigation so every page is reachable by a shallow, predictable path, and keep labels consistent between navigation and page titles. Order content by user priority, not stakeholder preference. List responsive-behavior questions (what collapses, what hides, what reflows) as explicit decisions for the frontend work. Do not add pages or content beyond the agreed scope; return additions to requirements review.
